🐍 Snake Water Gun Game

My first Python project! A simple command-line game where you play Snake, Water, and Gun against the computer and also supports a two-player mode.

🎮 How to Play
- Run the Python program.
- Choose Snake, Water, or Gun when prompted.
- The computer makes its choice.
- The winner is decided according to the game rules.

🛠️ Built With
- Python

🚀 How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
game.py
