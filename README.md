# snake-water-gun-game
A beginner-friendly Snake, Water and Gun game in python, featuring a bot opponent and a two-player mode.
FEATURES:-
1 play against a computer bot.
2 play with a friend.
3 random choices for the bot.
4 multiple rounds.
TECHNOLOGIES:-
1 python
2 python random module
HOW TO RUN?
1 install python 3.
2 download or clone this respository.
3 open a terminal in the project folder.
4 Run: "game.py"
